What it does

{{ app_name|default:"Recoup" }} is an AI revenue recovery agent for payment failures, checkout abandonment, subscription lapses, and overdue B2B invoices. It doesn't just flag the problem — it diagnoses the root cause, decides the most cost-effective intervention, executes it across real channels, and logs an auditable trail of exactly why it did what it did.

How it works

  1. 1
    Detect — payment failures (real Razorpay webhook), checkout abandonment, overdue invoices, and early-warning payment degradation before a hard failure even happens.
  2. 2
    Diagnose — classifies the root cause using Razorpay's real failure taxonomy, falling back to Gemini reasoning for ambiguous cases.
  3. 3
    Decide — a bounded, auditable ROI optimizer scores every candidate action by expected recovery value minus real channel cost, and picks the best one — or stops, if nothing clears the bar.
  4. 4
    Execute — real WhatsApp/email sends, Gemini-personalized (including Hinglish), with compliant stopping rules and human escalation for high-value or repeatedly-failed cases.
  5. 5
    Learn — recovery probabilities recalibrate from real observed outcomes after every batch, so the agent's decisions improve over time.
  6. 6
    Audit — every decision, action, and outcome is logged in an immutable, explorable timeline.

What makes this different

  • ◆
    Explainable by design — every decision shows every candidate action it considered and why it lost, not just the winner.
  • ◆
    One pipeline, every leak type — payment failures, abandonment, degradation, and receivables all flow through the same bounded engine instead of siloed point solutions.
  • ◆
    Predictive, not just reactive — flags payment degradation risk before a hard failure occurs.
  • ◆
    Cost-aware, always — will not spend more chasing a recovery than the recovery is worth, including its own AI-call costs.
  • ◆
    Self-improving — recovery probabilities recalibrate from real observed outcomes, not frozen assumptions.
  • ◆
    Customer-respecting — a transparent magic-link portal with a real one-click Razorpay payment link and a genuine opt-out.
  • ◆
    Safe to trust — shadow mode projects recovery before a single message is sent or a rupee moves.

For judges — quick orientation

  • Stack: Django + DRF, real Razorpay Test Mode webhook, real WhatsApp Cloud API + Gmail SMTP, Gemini (flash-lite/flash) for bounded reasoning tasks only — never for the money decision itself.
  • Covers from the brief: payment degradation → root cause → recovery action, checkout drop-off recovery, B2B receivables chaser, promise-to-pay tracker, Hinglish messaging.
  • The rule-based core (stopping rules, cost math) is deliberate, not a limitation — auditable, bounded decisions on money movement, with AI reasoning applied only where genuine judgment is needed.
  • Two live dashboards: /dashboard/ for admin/ops, an escalation queue for recovery agents after login.
